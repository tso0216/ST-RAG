# v4 web

`v4.rag` 的網頁介面：左邊聊天和工具呼叫，右邊地圖。地圖畫什麼由程式依工具呼叫決定，不經過 LLM。

```bash
PYTHONPATH=.:src .venv/bin/python -m v4.web
```

開 <http://127.0.0.1:8765>。`--db` 換資料庫、`--port` 換埠。需要的東西跟 `v4.rag` 一樣，也一樣會把新地點寫進資料庫。每次提問彼此獨立，同一時間只跑一題。

## 地圖怎麼畫

範圍看工具的參數；畫哪幾筆看回傳裡的編號（LLM 實際拿到的那一頁）；座標和內容從資料庫查。

| 來源 | 地圖上 |
|---|---|
| 解析出的行程 | 使用者的地點和每天的路線 |
| `find_place` | 候選地點；區域畫出邊界 |
| `list_places` | 範圍（邊界或半徑圈）和回傳的地點 |
| `measure` | 照順序編號的站、每段直線距離 |
| `search_notes` | 查詢範圍、有經驗的地點 |
| `search_moves` | 起訖範圍、移動的線（來回算一條） |
| `search_days` | 查詢的站、每一天一條路線 |
| `search_day_notes` | 評語講到的那幾天的路線 |
| `read_article` | 整篇的每日路線、地點和移動 |
| 答案 | 只畫實際引用到的經驗；編號不存在時加刪除線 |

沒有座標的資料不會畫在地圖上，但引用還是看得到。

## 檔案

| 檔案 | 做什麼 |
|---|---|
| `visual.py` | 工具呼叫、行程、答案 → 地圖場景 |
| `stream.py` | 接 `v4.rag` 的 `Log`，把進度變成一行一個 JSON 的事件串 |
| `app.py`、`__main__.py` | 伺服器和命令列，只開在本機 |
| `static/` | 前端（Leaflet，不用建置） |
